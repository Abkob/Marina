Marina on your iPhone

The quickest setup opens the check-in. A connected shortcut can save actual times directly with Apple’s date picker. Both work with Marina’s Vercel website.

Quick setup · open check-in

  1. Open Shortcuts → +. Name it “Marina check-in”.
  2. Add URL. Paste the check-in link from Marina’s Schedule → Proposed / Actual → help.
  3. Add Open URLs. Run it once and sign into Marina if needed.
  4. Add Apple’s Shortcuts widget to your Home Screen. Edit the widget and select “Marina check-in”.

It opens in a browser. The installed Home Screen app may have a separate sign-in. A shortcut cannot force iOS to open a particular installed web app.

Connected setup · save actual times

In Marina’s check-in help, select Connect Shortcuts and copy the private connection key. Do not put it in a URL or share the shortcut with that key included.

In the steps below, Marina URL means this website’s origin, with no trailing slash. Every Get Contents of URL action needs this header:

Authorization: Bearer YOUR_CONNECTION_KEY

Start with two shortcuts, “Marina Started” and “Marina Ended”. Use Format Date → ISO 8601 for all times. Keep the same request UUID if retrying a failed Start; an End retry is already safe.

“Marina Started”

  1. Get Contents of URL: Marina URL/api/schedule-shortcuts/context, method GET, with the header above. Save the result as Context.
  2. Get Dictionary Value → events from Context. Repeat with Each event: only keep ones with status = unknown and no actual_start. Build a list of their title values. Use Choose from List. Find the corresponding event dictionary by list index; preserve its occurrence_id and date. For identical titles, append the planned start time to each label.
  3. Ask for Input, type Date and Time, prompt “When did you start?”, default Current Date. Format the chosen date as ISO 8601.
  4. Generate UUID. Save it as Start ID.
  5. Get Contents of URL: Marina URL/api/schedule-shortcuts/start, method POST, body JSON, same Authorization header. Add the following fields using the saved variables:
{
  "session_id": "Start ID",
  "occurrence_id": "Chosen event occurrence_id",
  "date": "Chosen event date",
  "expected_running_id": "Context running_id",
  "started_at": "Chosen ISO 8601 date",
  "track_live": true
}

expected_running_id must be the actual context value, including JSON null when nothing is running. Do not send the word “null” as text. For an older event you are filling in later, use track_live: false so your current timer stays running. The website also offers a simpler hold-and-slide entry for these corrections.

“Marina Ended”

  1. GET the same context, with the same header.
  2. Get pending. Choose an activity by title and started_at, retaining its dictionary and id. This list includes earlier starts still awaiting an end.
  3. Ask for Input → Date and Time: “When did you end?”, default Current Date. Format as ISO 8601.
  4. POST to Marina URL/api/schedule-shortcuts/end, same header, JSON:
{
  "session_id": "Chosen pending id",
  "ended_at": "Chosen ISO 8601 date"
}

Read the response before showing success. If it contains error, show that message. A successful save returns serverNow and the saved timer state; End also returns minutes. There is no automatic end when you move on. Overlapping actual times require a corrected boundary and stay unconfirmed until fixed.

Add the widget

Put both shortcuts in a “Marina” folder. Add Apple’s Shortcuts widget to the Home Screen, edit it, and select that folder. iOS may open Shortcuts to show the event list or date picker. The widget does not display Marina’s live schedule or its custom hold-and-slide control.

To disconnect, return to Marina’s check-in help and select Revoke. A key only reads schedule context and records scheduled starts/ends; it cannot access notes, uploads, account settings, or unrelated timers.
