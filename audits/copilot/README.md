# Copilot audit reproduction

This directory contains **synthetic audit material**, not uploaded originals. No test starts the application server, reads production application rows, calls a live chat/embedding model, or changes a calendar.

Run on Node 24 after the normal project dependencies are installed:

```sh
npm run test:copilot-audit
npm test -- --maxWorkers=2
npm run lint
```

The audit has 219 cases: 202 ordinary passing checks and 17 expected failures. The existing unit suite has 962 passing tests in the controlled two-worker run. Vitest reports expected failures as passed. **That is reproduction of a known defect, not evidence of quality.** The desired assertions are preserved in `it.fails` tests so they can become ordinary regression tests after repair. Unexpected success causes the audit to fail and signals that promotion is required.

| File | Subject |
| --- | --- |
| `indexing.test.ts` | Actual chunk pipeline with synthetic extracted pages and mocked database writes; page/word/version defects; experimental window properties |
| `embedding.test.ts` | Actual embedding input builder, provider mocked; metadata, 600-character truncation and dimension validation |
| `retrieval.test.ts` | Actual search/fusion functions with controlled database candidates; scope, degradation, provenance, budgets and experimental source coverage |
| `pdf.test.ts` | Actual `pdf-parse` production wrapper against the two-page generated PDF |
| `scheduling.test.ts` | 80 seeded day-allocation workloads, 40 seeded hour layouts, dependency counterexamples and calendar boundaries |
| `conversation.test.ts` | Actual tool loop and proposal validation with scripted model responses; mixed source/task observations, entity-type confusion, retry and round limits |
| `candidateIndex.ts` | Experimental helpers only; never imported by application code |

Expected-failure issue IDs: IDX-01 (3 cases), IDX-02, IDX-03 (3), IDX-04, EMBED-01, RAG-01, RAG-02, RAG-03, VIS-01, VIS-02, PLAN-01, PLAN-02, CHAT-01. These are 13 distinct issues across 17 test cases.

The retrieval tests do not execute SQL or measure embedding quality. Their controlled rankings expose the behavior of the application when a candidate set has those properties. Scripted conversation tests measure software contracts, not a model's ability to choose the right tool or resist every injection.

## Real PostgreSQL experiment

Set `DATABASE_URL_TEST` to a local isolated PostgreSQL database whose name contains `test`, then run:

```sh
node audits/copilot/lexical-postgres.mjs
```

The script refuses nonlocal hosts and non-test database names. It runs eight `SELECT` expressions inside a read-only transaction, without touching application tables. English stemming improves some natural-language examples but also drops negation. This is why the study recommends evaluating multiple lexical strategies rather than blindly replacing `simple` with `english`.

## Real OCR experiment

The repository already contains the tiny synthetic PDF and PNG, generated by `build_pdf_fixture.py` using ReportLab and Pillow. Regeneration is optional and requires those Python packages. The PDF's first page has native text plus an image, and its second page has only the image. No user content is present.

If Tesseract.js is installed in a separate environment:

```sh
node audits/copilot/ocr-experiment.mjs --module /absolute/path/to/tesseract.js
```

First use downloads public English OCR weights into ignored `tmp/copilot-ocr/`; image recognition runs locally. Results are written there too. The recorded experiment used the bundled Tesseract.js runtime and recovered `NEBULA-731`, `Before: 25`, and `After: 45`; the native PDF parser missed all three. Worker startup took 4,057 ms and recognition took 865 ms on this machine. These single-run timings are not production performance estimates.

Recognizing chart labels does not establish chart interpretation. Docling, visual language models and ColPali were researched but not benchmarked or added as application dependencies. See [the full study and implementation plan](../../docs/copilot-replacement-study.md).
