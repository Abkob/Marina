Design evidence adopted:

- [NVIDIA hosted API](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-embed-1b-infer): separate `passage`/`query` input types, float vectors and explicit no-truncation. Trial inputs are conservatively bounded to 3,000 UTF-8 bytes, below the documented hosted 4,096-token input limit. The larger model-card context is not assumed to be the hosted limit.
- [NVIDIA model documentation](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-embed-1b): 2,048 dimensions. Validate identity, order, dimension, finite values and usable nonzero norms before scoring. Never pad or compare these vectors with the existing Gemini index.
- [Google embedding guidance](https://ai.google.dev/gemini-api/docs/embeddings): preserve documented Gemini 2 search/document prefixes and 3,072 dimensions. Gemini 2 aggregates list inputs; do not pretend a list produces independent passage embeddings. The comparison therefore retains the actual single-input production adapter.
